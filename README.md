# mehdi-labs

Open an issue with a weird problem. Let's build it together.

I'm Mehdi, a senior software engineer. Days are enterprise commerce. Nights and weekends
are AI agents, developer tooling and sports/fitness software. This repo is the front door
to that second half.

## On the bench right now

- **An AI agent for Shopify merchants.** Describe a discount in plain English, get a config
  that a Shopify Function executes. An eval harness gates every prompt change.
- **A regulatory checkout-fees app.** E-waste, battery and mattress recycling fees, per item,
  as config rather than code.
- **An Apple Watch running app.** Lay out your run screen on iPhone, see that exact layout
  on your wrist. Field-tested, App Store next.
- **A workout generation service.** One schema, two executors. The watch runs the program,
  the website renders it.
- **[medmansports.com](https://medmansports.com).** My training site. Static-first Next.js,
  a real training log, built to production standards for no reason other than practice.
- **[medmansports.ca](https://medmansports.ca).** A small tennis store on Shopify. The
  sandbox for trying things against real orders.

Most of these are private while they're being built. Ask and I'll walk you through any of them.

## How this works

1. Open an issue. Pick the template that fits.
2. Tell me the problem, what you've tried, and what "done" looks like.
3. I reply within a week. Labels show where it stands: `building`, `shipped`, `parked`.
4. If it turns into a build, it gets its own repo and the issue links to it.

This repo is the lobby, not the workshop. No code lives here.
